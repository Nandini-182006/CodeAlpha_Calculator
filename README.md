# Calculator Program

## Description
This project is a simple calculator developed in C Programming. It performs basic arithmetic operations using a switch-case statement.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- C Programming

## How to Run
1. Compile the program using a C compiler.
2. Run the executable file.
3. Enter two numbers.
4. Select an operation (+, -, *, /).
5. View the result.

## Sample Output
Enter first number: 10
Enter second number: 20
Enter choice: +
Result = 30.00
